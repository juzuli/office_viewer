Built for the pain points

Parity opens the file. These keep the host calm.

  • Soft-fail huge or corrupt Office files — the host stays up
  • PDF on its own path — never abort the process for a PDF
  • Sheet and slide parts you can actually see
  • Fit-width default and pinch that commits
  • Viewport-culled sheet tiles for large workbooks
  • Offline local open as the default story

FAQ

Is this an editor?
No. View only. We do not ship Save.
Does it upload my files?
No. Local open is the default.
Can hosts open docs users already have?
Yes — local DOCX, XLSX, PPTX, common ODF and legacy formats, and PDF.
iOS and Android?
Yes for v1. Web is planned, not claimed yet.
Why pay if the code is MIT?
Paid tiers buy response time and redistribution guidance — not a darker paint path.
